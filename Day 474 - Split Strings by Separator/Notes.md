# 📝 Notes – LeetCode 2788

## 🔍 Core Concept

**String Splitting:** Dividing a string into smaller substrings whenever a specified separator occurs.

Example:

```text
Input:  "a..b"
Split:  "."
Result: ["a", "", "b"]
Final:  ["a", "b"]
```

Empty substrings are excluded.

## ☕ Java Concepts

### 1. StringBuilder

Used to build strings dynamically.

```java
StringBuilder sb = new StringBuilder();
sb.append('a');
sb.append('b');
```

### 2. toCharArray()

Converts a string into a character array.

```java
String word = "hello";
char[] chars = word.toCharArray();
```

### 3. setLength(0)

Clears the existing StringBuilder.

```java
sb.setLength(0);
```

### 4. toString()

Converts StringBuilder into a String.

```java
String result = sb.toString();
```

## 🐍 Python Concepts

### 1. split()

Separates a string using a specified separator.

```python
word = "one.two.three"
parts = word.split(".")
```

Output:

```python
["one", "two", "three"]
```

### 2. Empty String Filtering

An empty string evaluates to `False`.

```python
if part:
    result.append(part)
```

### 3. List Comprehension

A concise way to construct lists.

```python
result = [
    part
    for word in words
    for part in word.split(separator)
    if part
]
```

## ⚡ Important Edge Cases

| Input | Separator | Expected Output |
|---|---|---|
| `"a.b"` | `.` | `["a", "b"]` |
| `"a..b"` | `.` | `["a", "b"]` |
| `".abc."` | `.` | `["abc"]` |
| `"..."` | `.` | `[]` |
| `"hello"` | `.` | `["hello"]` |

## 🏆 Revision Points

✦ Always exclude empty strings.

✦ Preserve the original order of substrings.

✦ Do not include the separator in the output.

✦ Process every word in the input list.

✦ Remember that Python `split()` preserves empty strings generated by separators.
