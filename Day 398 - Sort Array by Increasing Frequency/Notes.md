# ✦ Notes — LeetCode 1636

## ✦ What I Learned

- `HashMap` can be used to count how many times each number appears.
- Java's `Comparator` lets us define our own sorting rules.
- A lambda expression such as `(a, b) -> ...` provides the comparison logic.
- `Integer[]` can be used when we need comparator-based sorting because `int[]` is a primitive array.

## ✦ Sorting Rule

```text
1st Priority → Frequency Ascending
2nd Priority → Number Descending
```

## ✦ Example

```text
Frequency:
2 → 2 times
3 → 3 times
4 → 1 time

Sorted:
4, 2, 2, 3, 3, 3
```
