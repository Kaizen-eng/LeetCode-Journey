# ✦ LeetCode 1816 — Truncate Sentence
### Day 406

## ✦ Problem Understanding

Given a sentence `s` and an integer `k`, return a new sentence containing only the **first `k` words**.

The words are separated by a single space.

### Example

```text
Input:
s = "Hello how are you Contestant"
k = 4

Output:
"Hello how are you"
```
